SharpTimer — Surf / Bhop / KZ / MG timer plugin
================================================

Repo:    https://github.com/DEAFPS/SharpTimer
Release: https://github.com/DEAFPS/SharpTimer/releases/latest

How to set this up
------------------
1. Download the latest SharpTimer release ZIP.
2. Unzip it INTO THIS FOLDER (the one this README.txt is in).
3. After unzipping you should see:
     sharptimer/addons/counterstrikesharp/plugins/SharpTimer/SharpTimer.dll
     sharptimer/cfg/SharpTimer/config.cfg
   (plus other support files)

What this plugin powers
-----------------------
This single plugin is used by BOTH of these modes:
  - Surf
  - KZ / Climb
…because SharpTimer handles surf, bhop, KZ, and MG maps natively.

Verification
------------
After deploying, the diagnostic ("Check Installed Plugins") confirms:
  ✓ addons/counterstrikesharp/plugins/SharpTimer/SharpTimer.dll
exists in the CS2 server's csgo/ directory.

Prerequisites
-------------
- MetaMod base installed in csgo/addons/metamod/
- CounterStrikeSharp installed in csgo/addons/counterstrikesharp/
  (SharpTimer needs CSS v215+)
