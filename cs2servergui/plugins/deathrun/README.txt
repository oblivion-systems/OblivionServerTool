Deathrun Manager
================

Repo:    https://github.com/leoskiline/cs2-deathrun-manager
Release: https://github.com/leoskiline/cs2-deathrun-manager/releases/latest

How to set this up
------------------
1. Download the latest cs2-deathrun-manager release ZIP.
2. Unzip it INTO THIS FOLDER (the one this README.txt is in).
3. After unzipping you should see:
     deathrun/addons/counterstrikesharp/plugins/DeathrunManager/DeathrunManager.dll
   (if the plugin folder ships with a different name, rename it to match
   OR update _PLUGIN_VERIFY_FILES["deathrun"] in core.py)

Mode wiring
-----------
Powers the new "Deathrun" mode. Requires dr_* workshop maps.
