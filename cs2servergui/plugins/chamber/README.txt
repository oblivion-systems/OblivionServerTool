One in the Chamber
==================

Repo:    https://github.com/ddfigueiras/CS2-One-In-The-Chamber
Release: https://github.com/ddfigueiras/CS2-One-In-The-Chamber/releases/latest

How to set this up
------------------
1. Download the latest CS2-One-In-The-Chamber release ZIP.
2. Unzip it INTO THIS FOLDER (the one this README.txt is in).
3. After unzipping you should see:
     chamber/addons/counterstrikesharp/plugins/OneInTheChamber/OneInTheChamber.dll
   (if the plugin folder name differs, rename to match OR update
   _PLUGIN_VERIFY_FILES["chamber"] in core.py)

Mode wiring
-----------
Powers the new "One in the Chamber" mode — every player has a deagle that
one-shots anyone they hit.
