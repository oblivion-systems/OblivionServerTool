Scouts & Knives
===============

Repo:    https://github.com/hg-fortis/ScoutsNKnives
Release: https://github.com/hg-fortis/ScoutsNKnives/releases/latest

How to set this up
------------------
1. Download the latest ScoutsNKnives release ZIP.
2. Unzip it INTO THIS FOLDER (the one this README.txt is in).
3. After unzipping you should see:
     scoutsknives/addons/counterstrikesharp/plugins/ScoutsNKnives/ScoutsNKnives.dll

Mode wiring
-----------
Powers the new "Scouts & Knives" mode — classic scout + knife only on
standard competitive maps.
